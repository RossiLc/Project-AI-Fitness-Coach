# 知识库索引

本目录是 Open Fit 的长期知识库，保存跨需求稳定存在的背景、架构、规范和决策。

## 文档地图

- [项目背景](项目背景.md)：项目目标、用户、范围和阶段。
- [基础架构](基础架构.md)：模块、集成边界、数据流和状态模型。
- [通用规范](通用规范.md)：文档、命名、配置、安全和协作规则。
- [业务规范](业务规范.md)：企业微信、打卡、排行榜、提醒和健康建议规则。
- [代码规范](代码规范.md)：后续代码实现时遵循的通用约束。
- [AI协作规范](AI协作规范.md)：Agent 渐进式加载、OpenSpec 和 Superpowers 使用规则。
- [Superpowers运行时集成](Superpowers运行时集成.md)：项目级技能目录、运行时保真策略和降级规则。
- [闭环机制](闭环机制.md)：需求结束后的验证、归档和知识库回写流程。
- [决策记录](决策记录.md)：长期有效的关键决策。

## 维护原则

- 长期稳定结论写入知识库。
- 单次需求过程写入 `openspec/changes/<change>/`。
- 运行时技能资产位于 `.codex/skills/`，不是项目知识库正文。
- 每次需求结束前必须检查是否需要回写知识库。
