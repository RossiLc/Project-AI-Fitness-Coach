# 项目背景

Open Fit 是面向企业内部员工的 AI 健身教练与运动打卡平台。

## 产品形态

- 企业微信 AI 健身教练：普通员工的主入口，支持群内 @ 回复、文本/图片打卡、AI 教练咨询、活动规则查询、排行榜查询、每日小贴士和每周排行榜。
- Web 管理工作台：活动管理员和企业管理员的主入口，支持仪表盘、打卡管理、活动配置、排行榜、提醒任务、企业微信配置和成员映射。
- Web 员工入口：仅作为开发调试、补充录入和管理演示入口，不作为普通员工主要使用路径。

## 目标用户

- 普通员工：通过企业微信群机器人咨询运动建议、提交打卡、确认打卡、查询活动信息和查看排名；不要求注册或关注 Web 平台。
- 活动管理员：配置活动、查看仪表盘、管理规则。
- 企业管理员：配置企业微信机器人、自建应用和成员身份映射。

## 当前阶段

当前进入第一阶段可运行框架实现：先交付 Web 管理工作台、Node.js/NestJS API、worker、PostgreSQL、Redis/BullMQ、Prisma、本地文件存储和企业微信群机器人测试发送骨架。普通员工入口以企业微信群机器人为主；真实企业微信 OAuth、自建应用个人消息、完整多模态 AI 识别作为后续联调和增强推进。
## 当前产品边界更新

Open Fit 当前采用“企业微信员工入口 + Web 单管理员后台”的方案。普通员工不需要关注 Web 平台，也不需要在 Web 上打卡、查询或使用 AI 教练；员工侧统一通过企业微信群内的 `Open Fit 打卡助手` 和 `Open Fit AI 教练` 完成打卡、确认、咨询、活动规则查询和排行榜查询。

Web 站点只服务管理员运营，保留运营看板、成员管理、活动配置、排行榜管理四个模块。不再把员工调试入口、企业微信配置入口、角色权限入口和系统设置入口作为当前产品页面。
