# 通用规范

## 语言

- 项目自写文档、OpenSpec 产物、模板注释和新增说明统一使用中文。
- 英文专有名词可以保留，但必须放在中文语境中解释。
- 第三方运行时资产可以保留必要英文内容和原始结构，例如 `.codex/skills/` 中来自 Superpowers 上游的目录名、`name` 字段、触发词、脚本、示例和 prompt。
- 不为了中文化而削弱第三方运行时资产的约束能力；需要中文说明时，在项目知识库或入口文档中补充。

## 文档

- 长期知识写入 `docs/知识库/`。
- 单次需求过程写入 `openspec/changes/<change>/`。
- 临时探索可以写入当前 OpenSpec change；稳定结论要回写知识库。

## 安全

- 不提交企业微信密钥、webhook key、access token、员工真实数据或生产地址。
- 示例配置使用占位符。

## 工程边界

- `.codex/skills/**` 是 Agent 运行时资产，不是 Open Fit 业务源码。
- 后续创建 TypeScript、lint、测试或打包配置时，应排除 `.codex/**`。
